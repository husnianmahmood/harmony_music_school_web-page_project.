# Harmony Music School Website

This is an HTML and CSS lab project website for Harmony Music School.

## Files

- `index.html` - Main webpage
- `styles.css` - Website styling
- `images/` - Website pictures

## How to Make It Live with GitHub Pages

1. Open GitHub and create a new repository.
2. Upload these files directly to the repository:
   - `index.html`
   - `styles.css`
   - `README.md`
   - `images` folder
3. Go to repository `Settings`.
4. Open `Pages` from the left menu.
5. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Click `Save`.
7. Wait 1-2 minutes. GitHub will give you a live website link.

Important: `index.html` must be in the main/root folder of the repository, not inside another folder.
